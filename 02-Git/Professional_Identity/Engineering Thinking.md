# Engineering Communication Rules

## Rule 1
Evidence → Reasoning → Conclusion

## Rule 2
Never optimize an answer for what you think the interviewer wants.

Optimize it for engineering correctness.

## Rule 3
If the question contains an assumption, ask yourself:

- Is the assumption explicit?
- Is it ambiguous?
- Do I need clarification before answering?

## Rule 4
A professional engineer is comfortable saying:

"I'd like to clarify one assumption before answering."
